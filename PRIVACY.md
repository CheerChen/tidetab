# TideTab privacy policy

TideTab uses your Chrome browsing history to rank links on your new tab page.
It reads visited URLs, page titles, visit timestamps, visit identifiers, and how
you reached each page (for example, by typing its address). It reads
existing history when you install the extension and reads new visits as you browse.

TideTab stores visit records in IndexedDB and the ranked snapshot in
`chrome.storage.local`, in your Chrome profile. It can keep records after
Chrome expires them or you clear Chrome history. To delete the extension's
stored history and snapshot, remove TideTab from that profile. If you reinstall
TideTab, it will read any history that remains in Chrome.

TideTab does not transmit this data to the developer or any third party.
We do not sell it or use it for advertising. There is no
TideTab account, analytics service, or cloud sync. Opening a link takes you
to the destination website, as it would from a bookmark.

TideTab's use of information from Chrome APIs adheres to the
[Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq),
including the Limited Use requirements.
